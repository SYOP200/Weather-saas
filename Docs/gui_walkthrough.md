# 🖥 Weather SaaS — Visual GUI Walkthrough

This guide is a **visual-first walkthrough** of the Weather SaaS interface. It’s designed to help new users quickly understand the layout, controls, and workflows across **mobile and web**.

> All screenshots below are taken from the current app UI and reflect real layouts and components.

---

## 📱 Mobile App

### Mobile Dashboard (Home)

The home screen shows real-time conditions, quick stats, and forecast widgets.

![Mobile Dashboard](docs/screenshots/mobile-dashboard.png)

**What you’ll see:**
- Current temperature & conditions
- Location name (GPS-based)
- Forecast widgets
- Quick-access actions

---

### Severe Weather Alerts

Critical alerts appear prominently and can trigger push notifications.

![Mobile Alert](docs/screenshots/mobile-alert.png)

**Highlights:**
- NOAA-powered alerts
- Color-coded severity
- Tap to expand for details

---

### Location Management

Users can save multiple locations and switch instantly.

**Features:**
- Automatic GPS detection
- Manual city/ZIP search
- Favorites for quick access

---

### Offline Mode

When offline, cached weather data is displayed with a sync indicator.

**Behavior:**
- Last known conditions shown
- Automatic refresh when back online

---

## 🌐 Web Dashboard

### Web Overview Dashboard

The web dashboard provides a broader, analytics-focused view.

![Web Dashboard](docs/screenshots/web-dashboard.png)

**Sections include:**
- Current conditions panel
- Hourly & daily forecast charts
- Station data and observations

---

### Forecast Analytics

Advanced users can explore trends and patterns.

**Capabilities:**
- Temperature trends
- Precipitation probability
- Wind & pressure changes

---

### Stations Map

Nearby weather stations are displayed on an interactive map.

**Details shown:**
- Station ID
- Distance
- Last observation time

---

## 💳 Billing & Account

### Billing & Usage Dashboard

Account owners can view plans, invoices, and usage metrics.

![Billing](docs/screenshots/billing.png)

**Includes:**
- Current plan
- Usage meters
- Invoice history
- Payment method management

---

### Subscription Plans

Users can upgrade or downgrade plans at any time.

**Plans:**
- Free
- Pro
- Enterprise

Changes take effect immediately or at the next billing cycle.

---

## ⚙️ Settings & Customization

### Appearance & Theme

Users can customize:
- Light / dark mode
- Units (°F / °C, mph / km/h)
- Widget visibility

Settings sync across devices.

---

### Alerts & Notifications

Fine-grained alert controls:
- Alert types
- Severity thresholds
- Quiet hours

---

## 🧩 Plugins & Extensions

### Plugin Manager

Admins can enable or disable plugins per tenant.

**Examples:**
- Air Quality Index
- Pollen Forecast
- UV Index

Plugin data appears automatically in the UI once enabled.

---

## 🔐 Authentication & Security

### Login & Session Handling

- Secure JWT-based authentication
- Automatic session refresh
- Tenant isolation

- Enable location permissions for best accuracy
